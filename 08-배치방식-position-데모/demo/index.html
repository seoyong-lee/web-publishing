1. block / inline / inline-block 비교

block 1
block 2 (다음 줄로)
inline 1 inline 2 (같은 줄, width 지정 안 먹음)
inline-block 1 inline-block 2 (같은 줄, width 지정됨)

2. position 데모 (relative · absolute)

회색 박스는 position: relative 인 부모입니다.

position: relative (원래 자리는 차지, top/left로 살짝 이동)
position: absolute (부모=relative 기준, 원래 자리 차지 안 함)

3. sticky · fixed 데모

아래로 스크롤하세요. 초록 sticky 박스는 상단에 붙고, 검은 fixed 박스는 화면 왼쪽 아래에 고정됩니다.

↓ 계속 스크롤해서 초록 박스를 화면 상단까지 올려보세요
position: sticky (상단 도달 시 고정, 부모 영역 벗어나면 함께 사라짐)
sticky가 붙은 상태로 이 영역을 지나가면, 초록 박스는 다시 위로 올라갑니다.
fixed · sticky 확인용 추가 스크롤 영역입니다. 검은 fixed 박스는 계속 같은 자리에 있습니다.
position: fixed
