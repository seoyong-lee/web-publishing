# 수정 미션 (Day 4)

AI가 만든 코드를 읽고 직접 고칩니다. 필수 3곳 이상, 고친 곳은 아래 표에 적습니다.

## 먼저 — 내 것으로 바꾸기 (오전)

- [ ] 이름 · 소개 글을 내 글로 바꿨다
- [ ] 작업물 제목 · 설명을 내 것으로 바꿨다
- [ ] 이미지를 내 이미지로 바꾸고 alt 를 썼다
- [ ] head 의 title 을 내 이름으로 바꿨다
- [ ] 이메일 · 링크를 내 것으로 바꿨다

## 찾기 — 내 코드에서 표시하기

찾은 줄 위에 주석을 남깁니다.  HTML: `<!-- 여기가 nav -->`   CSS: `/* 패턴 2: 가로 내비게이션 */`

- [ ] header · nav · main · footer
- [ ] h1 (하나인지 확인)
- [ ] 패턴 1: max-width 와 margin: 0 auto (1컬럼)
- [ ] 패턴 2: display: flex · justify-content · align-items (nav)
- [ ] 패턴 3: 카드 목록의 display: flex 또는 grid

Tailwind 방식이면 class 에서 찾습니다:  max-w-…  mx-auto  flex  justify-between  items-center  grid  gap-…

## 고치기 — 3곳 이상 (오후)

| # | 고칠 곳 | 예 |
|---|---|---|
| 1 | 여백 · 본문 폭 | max-width 를 720px → 960px, 섹션 padding 늘리기 |
| 2 | nav 정렬 · 간격 | gap 값 바꾸기, 메뉴를 가운데로 (justify-content: center) |
| 3 | 카드 목록 | 3열 → 2열, 카드 사이 gap, 이미지 border-radius |
| 4 | 색 | 포인트 색 한 가지를 내 색으로 |
| 5 | 글자 | 제목 font-size, 본문 line-height |
| 6 | 상태 | 링크 · 버튼에 :hover 추가 |
