1. 구글 폰트 — link 태그 방식 (실제로 폰트가 바뀝니다)

head에 <link> 코드 3줄을 붙여넣고, font-family에 폰트 이름을 그대로 쓰면 끝입니다. 인터넷에서 폰트 파일을 실시간으로 받아옵니다.

2. 눈누(로컬 파일) — @font-face 방식

눈누(noonnu.cc) 같은 사이트에서 폰트 파일(.woff2 등)을 직접 다운로드해서 프로젝트 폴더(fonts/)에 넣고, CSS 맨 위에 @font-face로 등록하는 방식입니다.
이 폰트 파일은 실제로 포함되어 있지 않아서 아래 문단은 시각적으로 바뀌지 않습니다 — style.css의 @font-face 코드와, fonts 폴더에 실제 파일을 넣는 자리만 참고하세요.

이 문단은 로컬 폰트 파일(예: Pretendard)을 지정한 예시입니다.
