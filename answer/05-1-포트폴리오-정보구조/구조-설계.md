# 실습 ③-1 내 포트폴리오 정보 구조 잡기 — 예시 답안

강사 예시입니다. 내용은 각자 자기 이야기로 채웁니다.


## 1. 누구에게 보여 줄까요?

- 이 페이지를 볼 사람: 프로덕트 디자이너를 뽑는 채용 담당자
- 다 보고 나서 기억했으면 하는 한 가지: 문제를 정의하고 화면으로 빠르게 검증하는 디자이너


## 2. 영역별로 들어갈 내용

### 머리말 — header

- 이름 (h1): 이서용
- 한 줄 소개 (p): 사용자의 문제를 화면으로 푸는 프로덕트 디자이너
- 프로필 사진 설명 (img의 alt): 이서용 프로필 사진

### 메뉴 — nav

- 링크 세 개: 소개 · 프로젝트 · 연락처

### 소개 — main 안 section id="about"

- 소제목 (h2): 소개
- 나를 소개하는 문장 2~3개 (p): 기획부터 디자인, 간단한 구현까지 직접 해 보며 제품을 만듭니다. 리서치로 문제를 좁히고 프로토타입으로 빠르게 검증하는 과정을 좋아합니다.

### 프로젝트 — main 안 section id="projects"

- 소제목 (h2): 프로젝트
- 프로젝트 1
  - 이름 (h3): 온라인 강의 수강 신청 리디자인
  - 한 줄 설명과 내 역할 (p): 수강 신청 단계를 5단계에서 3단계로 줄였습니다. · UX 리서치, UI 디자인
- 프로젝트 2
  - 이름 (h3): 팀 결정 기록 도구
  - 한 줄 설명과 내 역할 (p): 회의에서 정한 내용을 한곳에 모으는 웹 서비스입니다. · 기획, 디자인
- 프로젝트 3 (선택)
  - 이름 (h3): 동네 책방 지도
  - 한 줄 설명과 내 역할 (p): 동네 독립 서점을 지도에서 찾는 모바일 웹입니다. · 디자인, 퍼블리싱

### 연락처 — footer id="contact"

- 이메일: hello@example.com
- 링크 (선택 · 노션 · 비핸스 · 링크드인 등): 없음
